# Government comparison v1

Free, bilingual, client-side comparison of up to three profiles. Rates 2021–2025 in dollars per $100 taxable value; FY2025 BRB reported outstanding principal, interest and repayment shown separately. Missing values are not zero. Comparisons are not household tax bills, equal-population burdens or a consolidated debt total. No account, payments or tracking. URL query ids holds only public profile slugs for sharing. Browser interaction testing pending.
