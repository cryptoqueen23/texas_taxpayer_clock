# Financial integrity and publication gates

Structural validation is not financial verification. Require source-specific coverage and total reconciliation before publication. Preserve revisions rather than overwrite earlier figures. Record discrepancies with both source versions and explanations. A rounding difference is flagged, not silently corrected. The default one-dollar tolerance is a review threshold, not universal accounting policy.

Never add overlapping taxable values or assume state/local debt is consolidated. An unconsolidated arithmetic sum must carry an overlap warning. Consolidated debt requires verified elimination schedules. Distinguish calculated levies, actual collections, appropriations and expenditures. Keep reporting periods and units explicit. Missing values remain null. No financial data is automatically approved by the validation functions.

The initial period validator accepts annual 2000–2099 periods and optional FY prefix and P1/P2 suffix. Historical and monthly source adapters require explicit extensions before import.
