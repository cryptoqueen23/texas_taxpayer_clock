# Ingestion protocol

Register only verified direct official file URLs with status `download_verified` and format `csv` or `xlsx`. Reference pages are not downloadable datasets. Run `python scripts/acquire.py` to archive files with SHA-256 manifests. Run `python scripts/ingest.py FILE MAPPING OUTPUT` to stage records using an explicit source-specific column mapping. Mapping keys: government_id, period, amount (column names), metric, unit, status, source_id; for XLSX also sheet and header_row. Preserve original identifiers as text; numeric Excel identifiers may require source-specific normalization. Staged data is not automatically published. Reconcile totals, coverage, duplicate jurisdictions and overlapping debt before approval. No live financial records have been ingested by this commit.
