# Automated review flags v1

Scope: English/Spanish government comparison, client-side flags on each selected government. Threshold: absolute percentage change >=20% in reported property tax rate or reported outstanding debt principal between adjacent 2021–2025 years, only when both numeric values exist and the earlier value is positive. Flag displays years, signed percentage and a link to the published methodology page. Missing or zero prior-year values are not treated as 0% changes; no extrapolation. These are data-review signals, not findings of error, fraud or wrongdoing. Rate changes can reflect voter decisions, appraisal shifts or classification/reporting differences. Debt principal changes can reflect issuance, repayment, defeasance or coverage changes. Source-level page/deep links remain a future enhancement; the methodology page is not a substitute for individual document verification. No monetization or data collection. Browser QA still required.
