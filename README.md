# Texas Taxpayer Clock

254 Counties. Thousands of Governments. Your Money.

Independent bilingual financial transparency project. No live deployment authorized yet.

## Development

`npm install` then `npm run dev`; `npm run build` creates the static site.

## Financial integrity

Reported balances are snapshots, not live transactions. Modeled rates are explicitly labeled. Missing values are null, never zero. Preserve source URLs, reporting periods, revisions and checksums. Do not consolidate overlapping debt without reconciliation.

Follow the Debt. Follow the Taxes. Follow the Money.
